# AWS architecture icon assets

The five SVGs in `slides/public/aws-icons/` are the official AWS service icons for Amazon S3, Amazon SQS, AWS Lambda, Amazon DynamoDB, and Amazon SNS.

Source: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/), Q3 2026 icon package.

The AWS page permits customers and partners to use these assets in architecture diagrams and presentation materials. Follow the current AWS icon guidance when reusing them.
